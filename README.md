# JavaScript OOPS Basics

This repository contains my JavaScript OOPS practice code with multiple class-based examples.
The goal of this repository is to understand core object-oriented concepts and write clean,
structured, and industry-style JavaScript code.

## Topics Covered
- Classes
- Objects
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

Each folder includes simple, readable examples that are useful for learning,
practice, and interview preparation.

This repository is updated regularly as I continue learning JavaScript.
